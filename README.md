Ce projet est une application pour la gestion financière et budgetaire, plus précisement pour déterminer les moyennes mensuelles, les coéfficients saisonniers et pour faire des prévisions.
 Configuration de l'application:
 _Créér la base de données postgreSQL : gestion_finance;
 _Modifier les identifiants dans config.py selon votre configuration PostgreSQL;
 _Installer les dépendances : pip install -r requirements.txt;
 _Initialiser la base de données : python init_db.py;
 _Lancer l'application : python app.py;
 _Accéder à l'application : http://localhost:5000
